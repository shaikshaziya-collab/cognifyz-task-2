# Cognifyz Internship – Task 2

A responsive and user-friendly feedback form developed as part of my Cognifyz Technologies Web Development Internship.

## 🚀 Project Overview

This project is a feedback form web application designed with a clean and modern interface. Users can enter their details, provide feedback, and submit the form to receive a confirmation response.

## ✨ Key Features

- 📝 User feedback form
- 📧 Email input
- 📱 Responsive design
- 🎨 Clean and modern user interface
- ✅ Form submission handling
- 💬 Confirmation response
- 🌐 Deployed using Render
